# Système décisionnel : élevage, santé animale et marchés

Projet de fin de module BC05 (RNCP39765). Chaîne décisionnelle complète pour un réseau d'éleveurs camerounais : 15 sources, ETL Talend, entrepôt PostgreSQL, ML/NLP et tableau de bord Power BI.

## Périmètre
- Régions : Adamaoua, Extrême-Nord, Ouest
- Espèces : bovins, ovins, caprins, volailles
- Période simulée : 2023 à 2025
- Les données du réseau sont synthétiques.

## Structure
config/ · data/ · generators/ · sql/ · etl/talend/ · ml_nlp/ · bi/ · docs/ · tests/

## Outils
PostgreSQL, MySQL, Talend, Power BI, Python
